# Great Scott's Tree & Leaf ID

**🌳 Live site: [jyounggsts.github.io/tree-id-flashcards](https://jyounggsts.github.io/tree-id-flashcards/)**

A free, browser-based flashcard app for practicing tree and leaf identification —
built for botany and arborist study. Covers 48 species commonly taught in North
American dendrology/forestry courses (broadleaf trees and conifers), with
multiple-choice and fill-in-the-blank modes, quizzing on common or scientific
names.

No build step, no dependencies, no backend — plain HTML/CSS/JS, deployable
straight to GitHub Pages.

## Running locally

Any static file server works, e.g.:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Data & images

- `data/species.json` — curated species list (common name, scientific name,
  family, leaf type, arrangement) used to generate questions and multiple-choice
  distractors.
- `data/attributions.json` — photo credit metadata (author, license, source
  link) for every image, generated by `scripts/fetch_images.py`.
- `images/` — one photo per species, pulled from Wikimedia Commons under open
  licenses (CC0, Public Domain, CC-BY, or CC-BY-SA). Full credits are viewable
  in-app via the "View photo credits" link, as required by the CC-BY / CC-BY-SA
  licenses.

To re-fetch or replace an image (e.g. if a better photo becomes available),
run:

```bash
python scripts/fetch_images.py <species-id>
```

with no arguments it fetches any species missing an image; pass one or more
species ids to force a re-fetch of just those.

## Accuracy note

Species data and images were manually reviewed for identification accuracy —
several initial automated image picks (wrong species, disease/gall close-ups,
herbarium microscope prints, unusable landscape shots) were caught and replaced
with verified leaf/foliage photos during development.
